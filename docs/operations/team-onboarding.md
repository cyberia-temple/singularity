## Карта репозиториев: что где лежит

**singularity** (Cyberia)
- `backend/laravel/` — сайт и кошелёк (Laravel + Vue). Почти вся логика Cyberia здесь: `pages/Wallet.vue`, `components/wallet/*`, мост `app/Services/Bridge*`, консоль операторов `/crm`.
- `frontend/mobile/` — Android/iOS-приложение (Capacitor, показывает живой сайт). Иконки: `node scripts/icon.mjs`.
- `frontend/desktop/` — десктоп (Electron). `frontend/extension/` — расширение-кошелёк (Chrome + Firefox).
- `crypto/hardhat/` — контракты EVM; `crypto/anchor/` — Solana; `services/telegram-bot/` — бот @cyberia_network_bot.
- `docs/` — эта документация (VitePress). `CLAUDE.md` / `AGENTS.md` — подробная карта для нейросетей, она самая полная.

**lain-labs/os** (агент Лейн)
- `src/plugins/*` — всё, что Лейн умеет: `desk` (paper desk $100), `trends` (тренды и сигналы), `guide` (как купить), `digest` (ежедневная сводка), `budget` (расход токенов), `forge` (сама пишет свои фичи), `chatter` (болтает в чате токена).
- `src/models/` — модели: OpenRouter, Groq (бесплатный пул), Claude/Codex CLI. `providers.ts` — как добавить провайдера.
- `apps/mobile/` — Android-приложение Lain OS; `apps/extension/` — расширение «Лейн в боковой панели».

**lain-labs/backend** (lain-os.com + chaos.fm)
- `/v1` — OpenAI-совместимый API Lain OS (модели OpenRouter и Groq, биллинг в микродолларах).
- `app/Services/Agent/*` — агент на сайте; `ChatReviewer` — ежедневный разбор чатов.
- `app/Services/Press/*` — пресс-деск: черновики, Buffer, политика публикаций, аналитика.
- `app/Mcp/Servers/ChaosServer.php` — chaos-mcp.

## Как работать с нейросетями (обязательно)

1. Подключи **chaos-mcp** (`https://chaos.fm/mcp`, ключ Lain OS как Bearer) в Claude/ChatGPT. Первый вызов в разговоре — `context_read`: там правила и контекст. Новое решение — `context_write` в раздел `notes`.
2. Правила для любого текста наружу: никаких ценовых обещаний; цифры только из инструментов; каждое утверждение — со ссылкой; фича «есть», только если открывается на сайте; секреты (ключи, сиды) никогда не вставлять в чат.
3. Claude тратим на код, деплой и решения. Посты, переводы, саммари — бесплатные модели (Groq, OpenRouter free). Подробности — документ «Лимиты нейросетей: план и экономия».

## Еженедельно

- Понедельник: `press:insights` присылает выводы аналитики — черновики постов и предложения фич (на доске консоли `/crm`). Разобрать: что делаем, что нет.
- Когда бот просит экспорт (X Analytics, Chrome Web Store) — выгрузить CSV и загрузить на chaos.fm/press → «Загрузить аналитику».
- `lain:usage-audit` (понедельник, Telegram): какие части Lain OS простаивают.
- Свериться с KPI-трекером (документ «KPI команды»).

## Как выпустить приложения

1. Влить PR в основную ветку и задеплоить сайт (магазинная версия решается на сервере).
2. Cyberia: `git tag app-v1.5.0 && git push origin app-v1.5.0` в singularity → GitHub Release (APK, desktop, расширение) + магазины (Play internal, TestFlight, Chrome Web Store, AMO), если заданы их секреты.
3. Lain OS: такой же тег `app-v*` в lain-labs/os → APK + zip расширения.
4. APK подписывается только при секретах `ANDROID_KEYSTORE_*` в репозитории; без них собирается debug-версия, и в релиз она не попадает.

## Что нельзя

- Коммитить или пересылать `.env`, ключи, сид-фразы, keystore.
- Писать о цене токенов с обещаниями; торговать токенами, зная непубличную информацию.
- Упоминать chaos.fm и chaos-mcp публично.
- Отвечать в X автоматически (политика X: автоответы и упоминания — только руками).
